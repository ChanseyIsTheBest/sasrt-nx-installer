sasrt-nx web installer

Builds the Nintendo Switch package of Sonic & All-Stars Racing Transformed from your own copy. Everything runs in this browser: nothing is uploaded.

version 0.1.0 (test)

1. Choose your game

The folder your copy of Sonic & All-Stars Racing Transformed was extracted to (with default.xex and Data/: GameAssets.M00, Frontend.M00, Movies/, sound/).

Nothing chosen yet.

2. Add the DLC (optional)

The game's downloadable content, as the Xbox 360 packages you have (LIVE, PIRS or CON files), or a folder of them. They go to switch/sasrt-nx/dlc/ as they are.

None.

3. Create the package

The game's archives (GameAssets.M00, Frontend.M00, GameData.M00) are packed with LZ4 (level 9, 256 KB blocks) on all of this computer's cores, and the re-encoded movies (and the sound packages where it helps) with ZXC (level 7, 512 KB blocks): about 1.9 GB smaller on the SD card, read as they were by the game. The zip downloads while it is written (about 2.4 GB, more with the DLC).

4. Copy it to the Switch

  1. If you have an older sasrt-nx, delete its switch/sasrt-nx/game_root folder first: an unpacked file left there is used instead of the packed or re-encoded one, and saves nothing.
  2. Extract sasrt-nx.zip to the root of the SD card: it makes switch/sasrt-nx/. The card must be exFAT, or FAT32 with every file under 4 GB (the packed files are).
  3. Start the game with a forwarder that has full memory (or a title takeover: hold R while starting a game, then open the Homebrew Menu). Not from the Album.
